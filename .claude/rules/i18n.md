# i18n and RTL rules

Locales: `en`, `fa-AF` (Dari), `ps-AF` (Pashto). Default `fa-AF`. Dari and
Pashto are RTL.

## Definitions live in one place

`packages/shared/src/i18n/locales.ts` is the single source of truth. Adding a
locale is a change there, plus one message file, plus a font subset decision.

Never hardcode a locale list anywhere else.

## Text

- No user-facing string literal in a component. Everything from
  `apps/web/messages/{locale}.json`.
- A new string goes into all three files in the same commit. An English string
  showing up in a Dari view is a bug, not a placeholder.
- The API returns error codes; the client owns the wording.

## Direction

`dir` is set once on `<html>`. Components must not decide direction themselves.

Logical properties only — `ms-`/`me-`, `ps-`/`pe-`, `start-`/`end-`,
`text-start`/`text-end`. Physical utilities fail lint.

Mirror icons that encode direction (back arrows, chevrons). Do not mirror icons
that do not (play, download, checkmark).

## Formatting

Use `Intl` for numbers, dates and currency, with the active locale. Never
concatenate a formatted value by hand — Dari and Pashto use the `arabext`
numbering system.

Time zone is `Asia/Kabul` everywhere.

## Known deprecation: setRequestLocale

`next-intl@4.13` marks `setRequestLocale` and `requestLocale` deprecated in
favour of `next/root-params`. They are still used here, with narrow
`eslint-disable` comments, because next-intl's static-rendering path still
depends on them and all three locales must stay pre-rendered (`● SSG`) for the
low-bandwidth budget.

**Upgrade trigger:** when next-intl documents the root-params equivalent for
static rendering. After migrating, confirm `pnpm --filter @afghan-it-academy/web
build` still reports `●` (SSG), not `ƒ` (dynamic), for `/en`, `/fa-AF` and
`/ps-AF`. If it reports dynamic, the migration is not done.

## Verifying an i18n change

1. Read the page in `fa-AF` and confirm the layout mirrors.
2. Confirm no untranslated English is visible.
3. Check the build output still shows all three locales as SSG.
